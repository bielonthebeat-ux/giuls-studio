# Giuls Studio

App personale di studio per telefono e tablet. Tutor locale basato su ricerca e regole; nessuna API AI.

I materiali, le chat e i progressi sono conservati nel browser del visitatore, senza backend o invii al repository. Esportare regolarmente un backup.

Aggiungere alla schermata Home da Safari su iPhone/iPad o da Chrome su Android. La disponibilità offline richiede un primo caricamento completo.
